# 06 — 素材评测工作台：上传视频+标注 → 拆帧 → 选帧跑 agent 对比

**What to build:** 让前端不再绑死固定 SHARD 数据集，支持用户放自己的素材跑 agent：
1. 上传视频 → 指定秒数区间拆帧 → 形成帧集合（缩略图网格）
2. 上传操作标注（parquet，与课程同构：17 布尔键 + j_left + j_right，用户从 NitroGen 拿）作为 gt
3. 选帧（缩略图点选 或 数字区间如 `1~20` 多选）→ 跑 agent 推理 → pred vs gt 对比
