# 05 — 在线推理：单帧 + 批量（Web 上跑 agent）

**What to build:** 在 Web 上真正跑 NitroGen agent，而不只是看静态结果。后端懒加载 ng.pt（首次调用才加载，缓存复用），提供两个能力：① 单帧在线推理——前端选帧号→后端抽帧→推理→返回 pred vs gt 动作对比；② 批量评测——跑完整测试集（200 帧，K=3 多数票）生成结果 JSON，前端刷新展示。

**Blocked by:** 01（spike 已验证推理路径）、02（后端骨架/API 模式）

**Status:** ready-for-agent

**决策（2026-08-22 用户确认）：** 先单帧后批量；懒加载；集成进 FastAPI（不另起 serve 进程）

- [x] 后端 `app/inference.py`：懒加载 InferenceSession（threading.Lock 防并发重复加载；实测加载 9s，非 30s）
- [x] `POST /api/predict`：单帧推理（帧号 fid 或秒→抽帧→get_action→decode），返回 pred buttons/j_left/j_right + gt 标注 + 17 键对齐（实测 12s 含首次加载）
- [x] `POST /api/evaluate`：批量 200 帧测试集（复用课程 evaluate.py 逻辑：K=3 多数票、PRED_ROW=0、帧号=chunk×1200+行号），返回指标 JSON（可用 metrics_lib 聚合）（实测 n=3 验证链路通）
- [ ] 单帧响应时间：加载后 <2s/帧（GPU 4.5GB 显存内）
- [ ] 前端在线推理面板（⏸ 等用户确认/新 skill）
- [ ] 验收：前端选帧→看到 pred vs gt 动作对比；批量评测跑完→指标更新
