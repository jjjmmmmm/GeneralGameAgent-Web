# 快速通检 · GeneralGameAgent-Web

> ≥5 条通检项，含 ≥1 异常路径；坏输入必须被拒绝。
> 执行方式：自动化测试 `cd backend && python -m pytest tests` + 手工 curl（下表给出手工命令）。

## 通检清单

| # | 项 | 命令/步骤 | 期望 | 类型 |
|---|----|----------|------|------|
| 1 | 服务健康 | `curl http://127.0.0.1:8000/api/health` | `{"status":"ok","versions":["baseline","ft"]}` | 正常 |
| 2 | 结果集多版本 | `curl /api/results` | 含 baseline 与 ft | 正常 |
| 3 | 指标与判定 | `curl "/api/metrics?version=baseline"` | `btn_accuracy=0.883`、`verdict.jl_corr_pass=false` | 正常 |
| 4 | **异常：未知版本被拒** | `curl "/api/metrics?version=nope"` | **404** 且 detail 明确 | 异常 |
| 5 | 段数据完整 | `curl "/api/segments?version=baseline"` | 21 段，含 `start/end/file/top5_frames/top5_diffs` | 正常 |
| 6 | 分页边界 | `curl "/api/frames?version=baseline&limit=50&offset=100"` | `total=200`、返回 50 条、首条 `idx=100` | 正常 |
| 7 | **异常：图片路径穿越被拒** | `curl "/api/figures/../results/baseline.json"` | **404**（不返回文件） | 异常 |
| 8 | 静态图 | `curl "/api/figures/curves/seq_060.png"` | 200 + `content-type: image/png` | 正常 |
| 9 | 素材帧路径穿越被拒 | `curl "/api/assets/x/frames/../../results/baseline.json"` | **404** | 异常 |
| 10 | 推理模型加载状态 | `curl /api/infer/status` | `{loaded, model}` 结构正确 | 正常 |
| 11 | **异常：未上传素材就拆帧** | 前端对空素材点"拆帧" | 前端禁用或后端 400 提示 | 异常 |
| 12 | 前端构建 | `cd frontend && npm run build` | `✓ built`，无 lint 错误 | 正常 |

> 坏输入覆盖：#4（未知版本）、#7/#9（路径穿越）、#11（前置条件不满足）。`pytest` 中对应：`test_metrics_unknown_version_404`、`test_figure_traversal_blocked`、`test_figure_missing_404`。
