## 1. 技术结论（查证过，不再重复踩坑）

### 1.1 帧号与标注对齐（课程 T1 结论）
`帧号 = chunk_id × 1200 + 行号`；测试集 = chunk_0032~0034（640~700s）。

### 1.2 模型推理关键参数
- `PRED_ROW = 0`（D7 实测排除时序偏移）
- 17 键标注 ↔ 21 键模型列映射硬编码于 `inference.py::BUTTON_TO_MODEL_COL`（复用课程 common.py 结论）
- 按钮阈值 `BTN_THRESHOLD = 0.5`；摇杆反归一化 [-1,1]
- `K=3` 多数票只对按钮投票（flow matching 随机性），摇杆取最后一次预测

### 1.3 Web 在线推理用哪个模型
- `baseline` → `D:/2+课产品/_models/ng.pt`（零样本，约 88%）
- `ft` → `<仓库>/train/ckpt/ft_lora.pt`（LoRA 调优后，约 91%）
- **前端默认选 ft**；切换模型后端释放旧 session 再加载（8G 显存单驻留）

### 1.4 抽帧临时文件
唯一文件名 `f{sec*60}_{pid}_{tid}_{time_ns}.png`（并发安全，防互删），用后即删。

### 1.5 结果集与版本化
- `backend/data/results/{baseline,ft,comparison}.json` 入库
- ft.json 的 `segments/demo` 为空 → 前端 ft 版本显示"该版本暂无分段曲线"
- 保存 ft 结果：`POST /api/evaluate {save:true, result}` 直接保存，不重跑（0.06s）

### 1.6 M2 最终结论（如实）
按键召回率 4.25%→65.75%（15 倍）、F1 0.079→0.643、准确率 88.3%→91.3%；**摇杆相关 +0.126 未达 0.4**（两次重试均如此，按 R3 预案如实呈现）。详见 `train/RESULTS.md`。

## 4. 环境坑（本机速查）

| 坑 | 现象 | 处理 |
|----|------|------|
| PowerShell 中文路径乱码 | 命令行传中文绝对路径变乱码；读无 BOM UTF-8 脚本中文乱码 | 脚本内用 ASCII/相对路径；`write_to_file` 工具可正确处理中文 |
| `start_api.ps1` 偶发启动失败 | 8000 无监听 | 用 python 子进程启动器（subprocess.Popen + 日志重定向）最可靠 |
| HuggingFace 离线 | 加载模型时联网下载 processor 卡 5 次重试 | `inference.py` 已设 `HF_HUB_OFFLINE=1` + `TRANSFORMERS_OFFLINE=1` |
| 8G 显存 | 两个模型不能同时驻留 | 切换模型时 `del` + `torch.cuda.empty_cache()` |
| ffmpeg | 抽帧失败报"系统找不到指定的文件" | 确认 ffmpeg 在 PATH、视频路径正确 |
