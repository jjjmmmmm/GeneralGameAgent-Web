# 技术选型比选 · GeneralGameAgent-Web

> 每个决策 ≥2 候选 + 放弃理由（防"随手上一个"）。决策时间：2026-08-21~22。

---

## D1 微调方案

**结论：LoRA（低秩自适应）**

| 候选 | 理由 | 放弃原因 |
|------|------|---------|
| **LoRA** | 8G 显存冻结视觉编码器+主干仅训 attention 低秩矩阵（~2~5% 参数）可行；不修改 NitroGen 源码即可旁路注入 | — |
| 全参微调 | 500M 参数 DiT + 1.2B 视觉编码器，8G 显存必然 OOM | 显存不足 |
| QLoRA | 需 4bit 量化基座，NitroGen 自定义模块量化兼容性未知 | 复杂且非必要（LoRA 已够） |
| 手写低秩旁路 | 若 peft 不适配自定义模型 | 备选（R7 预案），最终 peft 适配成功未启用 |

## D2 训练数据缓存

**结论：抽帧缓存（`train/cache/*.npy`）**

| 候选 | 理由 | 放弃原因 |
|------|------|---------|
| **抽帧缓存** | 统计集 38400 帧仅抽一次（首次约 8 分钟），训练/重训复用 | — |
| 每步重抽帧 | ffmpeg 逐帧进程开销大 | 训练循环里抽帧 IO 是瓶颈 |

## D3 后端框架

**结论：FastAPI**

| 候选 | 理由 | 放弃原因 |
|------|------|---------|
| **FastAPI** | 异步 + Pydantic 校验 + 自动文档；与 uvicorn 一体；课程生态熟悉 | — |
| Flask | 轻量 | 无请求模型校验、异步支持弱 |
| Django | 全家桶 | 过重，本项目仅 10+ 轻量端点 |

## D4 推理服务架构

**结论：集成进 FastAPI（同进程，懒加载）**

| 候选 | 理由 | 放弃原因 |
|------|------|---------|
| **集成进 FastAPI** | `/api/predict` 直接 import inference 模块；单服务部署；spike 已验证能跑 | — |
| 独立 serve 进程 | 模型常驻独立服务 | 多一个进程/端口/通信层；8G 显存不足以双驻留 |
| 前端直调 Python | 不现实 | 浏览器无法跑 torch |

## D5 模型加载时机

**结论：懒加载（首次推理才加载，切换模型释放旧模型）**

| 候选 | 理由 | 放弃原因 |
|------|------|---------|
| **懒加载** | 启动 Web 不占显存；`/api/infer/status` 告知状态；8G 显存单驻留 | — |
| 启动即加载 | 首请求快 | 后端启动慢 30s~1min；无推理时白占显存 |

## D6 前端框架

**结论：Vue3 + Vite**

| 候选 | 理由 | 放弃原因 |
|------|------|---------|
| **Vue3 + Vite** | 响应式 + 单文件组件；Vite 启动快/HMR；课程项目已用 Vue | — |
| React + CRA | 生态大 | 脚手架重、启动慢；团队对 Vue 更熟 |
| 原生 JS + ECharts | 无框架依赖 | 交互状态管理复杂（视图切换/版本/选择联动） |

## D7 图表库

**结论：ECharts**

| 候选 | 理由 | 放弃原因 |
|------|------|---------|
| **ECharts** | 折线/柱状/双 y 轴/缩放/图例开箱即用；深色主题可控 | — |
| Chart.js | 轻量 | 双轴/缩放/多系列叠加配置繁琐 |
| D3 | 灵活 | 成本高，本项目图表需求标准 |

## D8 Issue tracker / 任务管理

**结论：本地 markdown（`.scratch/<feature>/issues/`）**

| 候选 | 理由 | 放弃原因 |
|------|------|---------|
| **本地 markdown** | 个人项目、gh/glab 未装；issue 以文件形式在仓库内，AI 可读写；triage 五标签直接套用 | — |
| GitHub Issues CLI | 需 gh 登录 | 未装/无配置 |
| 云端看板 | 同步成本 | 与仓库解耦，AI 难访问 |

## D9 前端 API 版本化策略

**结论：API 从 v1 就多版本化（`?version=baseline|ft` 一等字段）**

| 候选 | 理由 | 放弃原因 |
|------|------|---------|
| **多版本化字段** | v2 只加视图不改数据格式，前端补对比=加视图非重写 | — |
| 先只做 baseline，后补 ft | 微调完数据结构变（多一套指标）组件全要改 | 返工风险（立项 R4 已验证此判断） |
