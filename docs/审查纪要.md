# 审查纪要 · GeneralGameAgent-Web

> 记录：谁审查、看了哪些方面、发现什么、是否已修。
> 项目为独立开发 + AI 助手（CodeBuddy）深度协作，审查分两类：① AI 助手 code-review（每次提交前）；② 用户人工 review（迭代反馈）。

---

## 1. 审查主体与方式

| 审查者 | 方式 | 时间 |
|--------|------|------|
| AI 助手（CodeBuddy） | 每次提交前通读 diff + `read_lints` + `npm run build` + `py_compile` | 全程 |
| 用户 | 前端预览逐项验收 + 反馈整改 | 2026-08-22~24 |
| 后端测试 | `pytest backend/tests`（15 用例） | 阶段 1 起 |

## 2. 审查方面（覆盖清单）

- 后端：API 一致性、多版本化、路径安全、指标口径、并发安全
- 前端：布局响应式、图表渲染、状态管理、推理互斥
- 数据：结果集 JSON schema、ft 保存逻辑
- 提交纪律：小步 commit（≤20 文件）、英文 message
