## 1. 实体

### 1.1 ResultSet（结果集，`backend/data/results/*.json`）

| 字段 | 类型 | 说明 |
|------|------|------|
| `version` | str | `baseline` \| `ft` |
| `label` | str | 人类可读标签（如"零样本（NitroGen 原生）"、"微调后（LoRA r8）"） |
| `metrics` | object | 六指标 + 判定（见 §1.2） |
| `frames` | Frame[] | 200 帧逐帧明细（总览曲线数据） |
| `segments` | Segment[] | 21 段 top5 差异帧（**ft.json 为空**，段图仅 baseline 生成） |
| `demo` | DemoFrame[] | 演示帧对比（**ft.json 为空**） |
| `button_freq` | object | 按钮频率（当前为空） |

### 1.2 Metrics（`metrics`）

```jsonc
{
  "btn_accuracy": 0.883,   // 按键准确率（n_correct/17 逐帧均值）
  "precision": 0.548,      // 触发精确率（both/pred）
  "recall": 0.042,         // 触发召回率（both/gt）
  "f1": 0.079,
  "jl_mse": 0.350,         // 摇杆 MSE（j_left）
  "jl_corr": 0.063,        // 摇杆相关系数
  "events": { "pred": 30, "gt": 400, "both": 17 },
  "n_frames": 200
}
```

### 1.3 Frame（`/api/frames` 与 `ft.json` 明细）

| 字段 | 类型 | 说明 |
|------|------|------|
| `fid` | int | 全局帧号（`= chunk×1200 + 行号`） |
| `sec` | float | 时间秒 |
| `jl_mse` | float | 该帧摇杆 MSE |
| `accuracy` | float | 该帧按键准确率 |
| `pred_press/gt_press/both` | int | 事件计数 |
| `jl_gt`/`jl_pred` | float \| null | 逐帧摇杆值（**在线评测新增**，用于推理曲线） |

### 1.4 Segment（`/api/segments`）

```jsonc
{ "start": 60, "end": 80, "file": "seq_060.png",
  "top5_frames": [3, 6, 5, 0, 12], "top5_diffs": [3.76, 3.56, 3.39, 3.17, 3.11] }
```

### 1.5 PredictResult（`/api/predict` 响应）

```jsonc
{
  "fid": 38400, "sec": 640.0, "infer_s": 0.32, "gt_available": true,
  "buttons": { "gt": ["dpad_left"], "pred": [], "n_gt": 1, "n_pred": 0, "n_both": 0, "n_correct": 16, "accuracy": 0.941 },
  "j_left": { "gt": [0.0, -1.0], "pred": [0.0, -0.5], "mse": 0.0168 }
}
```

## 2. 接口签名（后端，BASE = `http://127.0.0.1:8000`）

| 方法 | 路径 | 请求 | 成功响应 | 失败例 |
|------|------|------|---------|--------|
| GET | `/api/health` | — | `{status:"ok", versions:["baseline","ft"]}` | 服务未启动 |
| GET | `/api/results` | — | 结果集列表（version/label/更新时间） | — |
| GET | `/api/metrics` | `?version=baseline|ft` | Metrics + verdict（M4 判定） | 未知 version → 400/404 |
| GET | `/api/segments` | `?version=` | Segment[] | 同上 |
| GET | `/api/frames` | `?version=&limit=&offset=` | `{frames: Frame[]}` | 同上 |
| GET | `/api/comparison` | — | 逐帧 `{fid, gt_jl, base_jl, ft_jl}` | — |
| GET | `/api/demo` | `?version=` | DemoFrame[] | — |
| GET | `/api/figures/{name:path}` | name 支持子路径 `curves/seq_060.png` | PNG 文件 | 不存在/路径穿越 → 404 |
| POST | `/api/predict` | `{fid, k?, asset_id?, sec?, model?}` | PredictResult | 模型加载失败/标注不覆盖 → 500/400 |
| POST | `/api/evaluate` | `{n?, k?, save?, label?, asset_id?, fids?, result?, model?}` | `{frames, metrics}` | 同 predict；`save+result` 直接保存 |
| GET | `/api/infer/status` | — | `{loaded: bool, model: "baseline"\|"ft"\|null}` | — |
| POST | `/api/assets` | `{name}` | `{asset_id}` | — |
| POST | `/api/assets/{aid}/video` | multipart file | `{video: true}` | 无视频文件 |
| POST | `/api/assets/{aid}/actions` | multipart file | `{actions: true}` | 非 parquet |
| POST | `/api/assets/{aid}/actions-dir` | multipart files | `{n_chunks, rows}` | 找不到 `actions_processed.parquet` |
| POST | `/api/assets/{aid}/frames` | `{start_sec, end_sec, fps}` | `{n_frames}` | 素材未就绪 |
| GET | `/api/assets/{aid}/frames/{fname}` | — | PNG | 路径穿越/不存在 → 404 |
| DELETE | `/api/assets/{aid}` | — | `{deleted: aid}` | — |

### 2.1 `model` 字段约定

- `baseline`（默认）：加载 `D:/2+课产品/_models/ng.pt`（零样本）
- `ft`：加载 `<仓库>/train/ckpt/ft_lora.pt`（LoRA 调优后）
- 切换模型时后端释放旧 session 再加载新模型（8G 显存单驻留）

## 3. 成功/失败例（curl 可复现）

```powershell
# 成功
curl http://127.0.0.1:8000/api/metrics?version=ft
# 失败：未知版本
curl "http://127.0.0.1:8000/api/metrics?version=nope"
# → 404 {"detail":"结果集不存在: nope"}

# 失败：路径穿越被拒
curl "http://127.0.0.1:8000/api/figures/..%2F..%2Fresults%2Fbaseline.json"
# → 404 未找到图
```

## 4. 假实现边界（约定）

1. **段图/演示条仅 baseline**：ft.json 的 `segments/demo` 为空，前端 ft 版本显示"该版本暂无分段曲线"提示，不崩。
2. **批量对比无逐帧摇杆序列**：素材"批量对比"只返回聚合状态（press 布尔 + MSE），推理曲线只画"单帧推理/素材选帧推理/批量评测"三类有摇杆序列的数据。
3. **指标口径单一来源**：`metrics_lib.aggregate_frames` 与课程 `evaluate.py` 对齐；后端与 `train/evaluate_ft.py` 不得各自实现一套口径。
4. **结果可复现**：同一评测跑两次，JSON 结构一致、数值容差内可复现（flow matching 随机性，K=3 只对按钮投票）。
