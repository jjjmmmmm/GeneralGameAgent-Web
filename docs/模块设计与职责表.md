# 模块设计与职责表 · GeneralGameAgent-Web

> 配套 `docs/立项书.md`。模块划分、输入/输出/依赖、F1~F5 对照。
> 设计原则：**只读复用课程产物（模型/数据/NitroGen 模块），本项目自研的是"管线 + 服务 + 前端"三层**。

---

## 1. 模块总览

| 模块 | 类型 | 职责 | 对应必做项 |
|------|------|------|-----------|
| `train/` | 离线管线（CLI） | 数据管线 → LoRA 训练 → 评测 → 结果导出 | F1、F2 |
| `backend/` | FastAPI 服务 | 结果集多版本 API + 在线推理 + 素材工作台 | F3、在线推理 |
| `frontend/` | Vue3 SPA | 查看器 / 在线推理 / 素材工作台 UI | F4、F5 |
| `docs/` | 文档 | 立项/开发/验证/交付全周期记录 | 交付 |

---

## 2. `train/` 模块

| 子模块/脚本 | 输入 | 输出 | 依赖 |
|------------|------|------|------|
| `data_pipeline.py` | ng.pt、SHARD 标注（chunk 0~31）、视频 | 抽帧缓存 `train/cache/*.npy` + 动作样本 | ffmpeg、polars、torch |
| `train_lora.py` | 缓存样本 + ng.pt | `train/ckpt/ft_lora[_r16].pt` | torch、peft（或手写 LoRA）、NitroGen 模块 |
| `evaluate_ft.py` | ng.pt / ft_lora.pt + 测试集（chunk 32~34） | baseline vs ft 对比指标 | NitroGen `InferenceSession`、ffmpeg |
| `export_ft_json.py` | 评测结果 | `backend/data/results/ft.json` | — |
| `export_comparison.py` | baseline + ft 逐帧评测 | `backend/data/results/comparison.json` | 同上（需 `HF_HUB_OFFLINE=1`） |
| `spike.py` | ng.pt + 最小 batch | loss 是否可算（阶段 0 结论） | NitroGen 模块 |

**职责边界**：train 只产出"权重 + 结果 JSON"，不负责 Web 服务；所有路径硬编码可复现（见 `train/RESULTS.md` 配置表）。

---

## 3. `backend/` 模块

| 子模块 | 职责 | 关键接口 |
|--------|------|---------|
| `app/main.py` | FastAPI 路由、请求模型、结果集读写 | `/api/results|metrics|segments|frames|comparison|demo|figures|predict|evaluate|infer/status|assets` |
| `app/metrics_lib.py` | 指标聚合口径（与课程 evaluate.py 一致） | `aggregate_frames()` |
| `app/inference.py` | 懒加载模型（baseline/ft 切换）、抽帧、单帧/批量推理 | `predict_fid()` / `run_evaluate()` |
| `app/assets.py` | 素材工作台：目录/元数据/视频/标注/拆帧 | `create_asset()` / `upload_*` |
| `data/results/` | 结果集 JSON（baseline/ft/comparison，入库） | 版本化数据源 |

**职责边界**：inference.py 只依赖"模型权重 + 视频 + 标注"，不感知前端；metrics 口径单一来源在 `metrics_lib.py`。

---

## 4. `frontend/` 模块

| 子模块 | 职责 | 依赖数据 |
|--------|------|---------|
| `src/lib/api.js` | API 封装（所有 `/api` 调用） | 后端端点 |
| `src/App.vue` | 单页视图：查看器 / 在线推理 / 素材工作台 | metrics/segments/frames/comparison/demo/predict/evaluate/assets |
| ECharts | 总览图 / 叠加图 / 分段图 / 推理曲线 | frames/comparison/segments/infer 结果 |

**职责边界**：前端只消费后端 JSON，不做指标计算；版本切换（baseline/ft）通过 `?version=` 参数，模型选择通过 `model` 参数。

---

## 5. F1~F5 对照

| 必做项 | 落地模块 | 验证方式 |
|--------|---------|---------|
| F1 LoRA 微调管线 | `train/data_pipeline.py` + `train_lora.py` | `evaluate_ft.py` 出对比表；`train/RESULTS.md` |
| F2 微调后 M4 评测 | `train/evaluate_ft.py` + `export_ft_json.py` | `backend/data/results/ft.json` 指标 |
| F3 后端 API 多版本化 | `backend/app/main.py` | `curl /api/metrics?version=baseline|ft` |
| F4 前端 v1 查看器/仪表盘 | `frontend/` 查看器页 | 浏览器交互 |
| F5 前端 v2 对比视图 | `frontend/` 版本选择器 + 叠加图 | 切换版本指标/曲线变化 |

---

## 6. 里程碑 M0~M3 对照

| 里程碑 | 完成标志 | 涉及模块 |
|--------|---------|---------|
| M0 | 1 训练 step 跑通，loss 下降，显存<8G | `train/spike.py` |
| M1 | 后端 API + 前端 v1 展示 baseline | `backend/` + `frontend/` |
| M2 | ft 权重 + 测试集评测（按键达标；摇杆如实未达标） | `train/` |
| M3 | 前端 v2 对比视图 + 文档收尾 | `frontend/` + `docs/` |
