## 2. 数据流总览（训练）

```
帧图像 ──img_proc──▶ frames(B,1,3,256,256)
标注 ──pack_actions──▶ actions(B,18,25) + actions_mask(B,18,25)
                                            │
                      forward(data) ◀────────┘
                        ├─ encode_images → visual_features(B,1,256,1024)
                        ├─ sample_time → t (Beta, ~[0,0.999])
                        ├─ 加噪：noisy = (1-t)*noise + t*actions；velocity = actions - noise
                        ├─ action_encoder(noisy, t_discretized, embodiment_id) → action_features
                        ├─ prepare_input_embs（拼 VL/SA token 序列 + 位置编码）
                        ├─ vl_self_attention → DiT(timestep=t) → action_decoder → pred(B,18,25)
                        └─ MSE(pred, velocity) × mask → loss
```

## 3. 训练接口 `forward(data: dict) -> dict`

### 3.1 输入 data 的键（tokenizer.encode 输出）

| 键 | shape | 说明 |
|----|-------|------|
| `images` | (B, 1, 3, 256, 256) | img_proc 处理后的帧（B=1 时需 unsqueeze(0)） |
| `actions` | (B, 18, 25) | 打包动作（按钮+双摇杆，见 §5） |
| `actions_mask` | (B, 18, 25) | 有效动作掩码（全 True） |
| `has_real_action` | (B,) | 是否有真实动作 |
| `vl_token_ids` | (B, 256) | 视觉 token 占位序列（_IMG_TOKEN=1 ×256，左 padding _PAD_TOKEN=0） |
| `sa_token_ids` | (B, 18) | 动作 token 占位（_ACT_TOKEN=4 ×18） |
| `vl_attn_mask` | (B, 256) | VL 注意力掩码（左 padding 为 0） |
| `dropped_images` | (B, 1) | 是否丢弃帧（训练全 False） |
| `embodiment_id` | (B,) | 恒为 0（单 embodiment） |
| `game_ids` | (B,) | 恒为 0（无条件） |

> 注意：无 batch 时 tokenizer 输出 2D，需沿 dim0 unsqueeze 一次（inference_session 就是这么做的）。

### 3.2 内部流程（forward 逐段）

1. **set_frozen_modules_to_eval_mode()**：被冻结的模块切 eval（防止 BN/Dropout 干扰），本模型全可训所以无操作。
2. **encode_images**：`vision_encoder(images)["last_hidden_state"]` → rearrange 成 (B,1,256,1024)。
3. **采样时间**：`sample_time` = `(1 - Beta(1.6, 0.8).sample(B)) * 0.999`（连续 t ∈ (0, 0.999]）。
4. **加噪与速度**：`noisy_trajectory = (1-t)*noise + t*actions`；`velocity = actions - noise`。
5. **t 离散化**：`t_discretized = (t * 1000).long()`（用于 action_encoder 的时间嵌入与 DiT 的 timestep）。
6. **动作编码**：`action_encoder(noisy_trajectory, t_discretized, embodiment_id)` → (B,18,1024)。内部：MLP 编码动作 + 正弦时间编码 concat → 两层 swish MLP。
7. **序列组装**：`prepare_input_embs` 把视觉特征填入 vl 序列、动作特征填入 sa 序列，加位置编码（add_pos_embed=true）。
8. **主干**：vl_self_attention(vl_embs) → DiT(hidden_states=sa_embs, encoder_hidden_states=vl_embs, timestep=t_discretized)。
9. **解码**：`action_decoder(model_output, embodiment_id)` → pred(B,18,25)。
10. **loss**：`F.mse_loss(pred_actions, velocity, reduction="none") × (has_real_action × actions_mask)`，除以 mask 和。返回 `{"loss": loss}`。

### 3.3 训练需构造的输入数据（本项目的做法）

```python
data = {
    "images": pixel_values,          # (B,1,3,256,256)
    "actions": actions,              # (B,18,25) float
    "actions_mask": actions_mask,    # (B,18,25) bool 全 True
    "has_real_action": has_real,     # (B,) bool 全 True
    "vl_token_ids": vl_ids,          # (B,256) long
    "sa_token_ids": sa_ids,          # (B,18) long
    "vl_attn_mask": vl_attn_mask,    # (B,256) bool
    "dropped_images": dropped,       # (B,1) bool 全 False
    "embodiment_id": emb_ids,        # (B,) long 全 0
    "game_ids": game_ids,            # (B,) long 全 0（forward 用 data.get("game_id") 取，取不到即 None，无条件无影响）
}
```

> 最稳路径：直接调 `tokenizer.encode(...)`（train 模式）拿前 8 个键，再补 batch dim，不手拼 token 序列。

## 4. 推理接口 `get_action(data) -> {"action_tensor": (B,18,25)}`

- 输入键与 forward 相同（除 actions/actions_mask/has_real_action 不需要）。
- 从 `randn(B,18,25)` 出发，Euler 积分 16 步：`t = i/16`，`t_disc = int(t*1000)`，velocity = model 输出，`actions += dt*velocity`。
- **注意不一致点**：get_action 用 `data["game_ids"]`（复数，必填），forward 用 `data.get("game_id")`（单数，可选）。本项目无条件分支，均无影响，但自研循环别混用。
- 解码：`tokenizer.decode` 按 `old_layout=False` 拆回 j_left/j_right/buttons（[0,1] 摇杆 → 反归一化 [-1,1]，按钮 >0.5 阈值）。

## 5. 动作打包布局（关键）

- `max_action_dim=25` = **21 按钮 + j_left(2) + j_right(2)**（`old_layout=False`，ng.pt 实测）。
- 训练打包（tokenizer.pack_actions）：`np.concatenate([buttons, j_left, j_right], axis=-1)`。
- 摇杆**归一化到 [0,1]**（(x+1)/2）后 concat；推理时反归一化回 [-1,1]。
- 按钮为 0/1 连续值（不是离散 logit）。
- 课程 `common.py` 的 `MODEL_BUTTON_DIM=21`、`MODEL_STEPS=18` 与此完全吻合。

## 6. 视觉输入处理

- `AutoImageProcessor.from_pretrained("google/siglip2-large-patch16-256")` 处理单帧 HxWx3 RGB → `pixel_values`（1,3,256,256）。
- **首次运行需联网下载视觉编码器与 processor**（HF_HUB_OFFLINE=1 时不可用；无代理需 hf-mirror）。
- 课程评测已封装：`img_proc([obs], return_tensors="pt")["pixel_values"]`。

## 7. LoRA 微调落点（供阶段 2）

- DiT 主干：`model.model`（`flow_matching_transformer/modules.py`），8 层 `BasicTransformerBlock`，注意力用 **diffusers `Attention`**（self.attn1/attn2 + cross-attn），LoRA 低秩旁路挂 to_q/to_k/to_v/to_out。
- VL mixing：`model.vl_self_attention_model`，4 层，同结构，可选 LoRA。
- 视觉编码器 1.2B 级（siglip2-large）不训；动作编码器/解码器很小，可训或冻结。

## 8. 已知坑（自研循环注意）

1. tokenizer 输出无 batch，必须 unsqueeze(0)。
2. `images` 输入 forward 前需是 (B,1,3,256,256)，**RGB float**（img_proc 归一化后）。
3. `actions_mask` 与 `has_real_action` 必须提供，否则 loss 掩码运算崩。
4. forward 内 `sample_time` 每次采样新 t → 同输入两次 loss 不同（随机性，评测需 K=3 多数票）。
5. 冻结模块需 `set_frozen_modules_to_eval_mode()`（LoRA 时主干被部分冻结会触发）。
6. ng.pt 为 float32 训练权重（`model_dtype: float32`），8G 显存需 fp16/bf16 autocast + 冻结视觉编码器。
