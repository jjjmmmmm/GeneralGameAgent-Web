# 排错记录 · GeneralGameAgent-Web

> 按排错协议（`harness/07-排错协议.md`）五项归档：现象 / 期望 / 日志 / 文件 / 已尝试。

## E1 · 保存为 ft 结果报 `[Errno 2] 找不到 f38418.png`（已修 c11d55a）

- **现象**：前端"保存为 ft 结果"→ 500：`评测失败: [Errno 2] 系统找不到指定的文件。: '...\_tmp_frames\f38418.png'`
- **期望**：保存应成功
- **日志**：`backend/_uvicorn.log` 无 traceback；错误 detail 定位到抽帧临时文件缺失
- **文件**：`backend/app/inference.py::fetch_frame`
- **根因**：抽帧用固定文件名 `f{sec*60}.png`，并发请求（批量评测+保存/单帧）抽同一秒时 A 读后删、B 再读文件已消失
- **已尝试/修复**：文件名加 `{pid}_{tid}_{ns}` 唯一后缀 + try/finally 清理 + ffmpeg 失败带 stderr 报错；evaluate 3 帧复测通过

## E2 · API 离线 / 8000 端口无监听（反复出现）

- **现象**：前端右上角"API 离线"，`/api/health` 连接失败
- **期望**：后端 8000 常驻监听
- **日志**：`backend/_uvicorn.log` 为旧进程内容或为空；`netstat :8000` 无 LISTENING
- **文件**：`backend/scripts/start_api.ps1`
- **根因**：`Invoke-CimMethod` 传含中文路径的命令串，跨进程嵌套调用时编码乱码 → cmd 启动失败无日志
- **已尝试/修复**：改用 python 子进程启动器（`subprocess.Popen` + 日志重定向）可靠；`netstat` 需在启动 15s 后检查（时机太早会误判）

## E3 · 图表"穿模"/文字重叠（多轮）

- **现象**：① 曲线图顶端标题/图例重叠；② 标题与 y 轴坐标注释（MSE/j_left）重叠；③ x 轴"帧号"在最右端被裁剪；④ 左上角第二行副标题重叠
- **期望**：标题、图例、坐标注释互不遮挡
- **文件**：`frontend/src/App.vue::renderChart/renderCmpChart/renderSegChart`
- **根因**：ECharts title/legend 默认都居中挤在顶部；title 左对齐后又撞上 y 轴 name（坐标注释）；xAxis.name 默认在轴末端贴边
- **已尝试/修复**：`itemGap`+`lineHeight` 拉开主副标题；title 居中 + legend 右上；`xAxis.nameLocation:'middle'`；副标题缩短防换行（ab0e260/2b97c3a/95370d4）

## E4 · 首页显示旧数据 / 批量测试结果不进曲线（已修 b02f0d5 / 87ec892）

- **现象**：① 批量评测后首页指标不变；② 素材选 5 帧推理曲线出现 6 个点；③ 批量评测结果不进曲线图
- **期望**：推理结果即时反映到曲线与首页
- **文件**：`frontend/src/App.vue`、`backend/app/inference.py`
- **根因**：① 首页默认版本 baseline，批量评测结果未保存不会入 ft.json；② 曲线图混入历史单帧推理点（5+1=6）；③ 后端 evaluate 未返回逐帧摇杆序列
- **已尝试/修复**：`lastInfer` 只显示最近一次推理结果；后端 rows 加 `sec/jl_gt/jl_pred`；保存 ft 直接回传结果不重跑（0.06s）+ 自动切 ft 版本

## E5 · Web 批量测试准确率 88% 而非 91%（模型用错）

- **现象**：调优完成（ft 91.3%），但 Web 在线推理/批量评测结果始终约 88%
- **期望**：Web 应测调优后模型
- **文件**：`backend/app/inference.py`
- **根因**：`_load_session()` 硬编码 `ng.pt`（baseline），从未加载 `ft_lora.pt`
- **已尝试/修复**：`model` 参数（baseline|ft）+ 懒加载切换（释放旧模型）；前端模型选择器默认 ft（87ec892）

## E6 · HuggingFace 离线卡死（加载模型 5 次重试失败）

- **现象**：加载 ft 模型时日志反复 `Retrying [N/5] ... https://huggingface.co/...processor_config.json`，最终超时
- **期望**：离线环境直接走本地缓存
- **日志**：`_uvicorn.log` 尾部重试记录；`~/.cache/huggingface/hub` 有 `models--google--siglip2-large-patch16-256` 且含 `preprocessor_config.json`
- **文件**：`backend/app/inference.py` 顶部
- **根因**：transformers `AutoImageProcessor.from_pretrained` 尝试联网校验 `processor_config.json`
- **已尝试/修复**：模块顶部设 `HF_HUB_OFFLINE=1` + `TRANSFORMERS_OFFLINE=1`（87ec892）

## E7 · 顶栏"查看器/在线推理"按钮收窄变竖长（已修 a1ae601）

- **现象**：浏览器窗口收窄后两个导航按钮被压成竖长方形
- **期望**：任意宽度按钮保持横排
- **文件**：`frontend/src/App.vue` 顶栏样式
- **根因**：flex 三区被压缩，`nav-btn` 文字换行
- **已尝试/修复**：`.topbar{flex-wrap:wrap}` + 三区 `flex-shrink:0` + `nav-btn{white-space:nowrap}`；≤900px 隐藏副标题

- **现象**：素材评测工作台选中素材后帧图不显示
- **期望**：帧网格图片可见
