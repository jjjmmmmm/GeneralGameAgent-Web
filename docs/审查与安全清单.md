# 审查与安全清单 · GeneralGameAgent-Web

> 密钥 / 依赖 / 鉴权 / 注入，每项有验证方式或"不适用"理由。
> 性质：本地开发工具（127.0.0.1 监听），无用户数据、无多租户、无支付——**大部分项"不适用"**，以下如实逐项。

---

## 1. 密钥与敏感信息

| 项 | 状态 | 说明 / 验证 |
|----|------|-------------|
| 密钥/令牌 | ✅ 无 | 仓库无 `.env`、`*.pem`、`*.key` 等；`.gitignore` 已排除 |
| 模型/数据路径硬编码 | ✅ 可接受 | `inference.py` 硬编码 `D:/2+课产品/...` 为本地课程路径；属环境事实，非敏感 |
| 泄露检查 | ✅ | `git grep -i "password\|api_key\|secret\|token"` 无命中（除代码注释） |

## 2. 依赖安全

| 项 | 状态 | 说明 / 验证 |
|----|------|-------------|
| Python 依赖 | ✅ | `backend/requirements.txt`：fastapi/uvicorn/pytest/httpx/python-multipart（无高危包）；推理栈用课程 venv 固定版本 |
| Node 依赖 | ✅ | `frontend/package.json`：vue/echarts/vite 三个正式依赖（+dev 插件），无来源不明包 |
| 依赖审计 | ⚠️ 建议 | 上线前跑 `pip-audit` / `npm audit`；当前为课程锁定环境，风险可控 |

## 3. 鉴权与访问控制

| 项 | 状态 | 说明 |
|----|------|------|
| 鉴权 | ✅ 不适用 | 本地单用户工具，无登录体系；不面向公网 |
| 监听地址 | ✅ 本机 | uvicorn `--host 127.0.0.1`，不对外暴露 |
| CORS | ⚠️ 需收紧 | `allow_origins=["*"]` 为开发期放宽（`main.py` 注释已标注"上线前收紧"）；见 `docs/差距清单.md` G6 |

## 4. 注入与输入校验

| 项 | 状态 | 验证方式 / 说明 |
|----|------|----------------|
| 路径穿越（静态图） | ✅ 已防 | `main.py::get_figure` 用 `p.is_relative_to(FIGURES_DIR)` 拒绝 `../`；测试 `test_figure_traversal_blocked` |
| 路径穿越（素材帧） | ✅ 已防 | `/api/assets/{aid}/frames/{fname}` 同样 `is_relative_to` 校验 |
| 未知 version | ✅ 已拒 | `/api/metrics?version=nope` → 404；测试 `test_metrics_unknown_version_404` |
| 素材 id 注入 | ✅ 已防 | 素材路径基于 `ASSETS_DIR/aid`，aid 来自 `create_asset` 生成的 UUID，非用户输入拼接 |
| SQL 注入 | ✅ 不适用 | 无 SQL（polars 读 parquet，非数据库） |
| 命令注入 | ✅ 已防 | `subprocess` 调用 ffmpeg 时参数为列表（非 shell 字符串），文件名/秒数由内部计算；`fetch_frame` 唯一文件名避免竞态 |
| 上传文件类型 | ⚠️ 建议限制 | 素材上传接受任意文件（后端按需解析 parquet）；上线前加扩展名/大小限制（见 G6） |
| 前端 XSS | ✅ 已防 | Vue 模板默认转义；无 `v-html` 渲染外部数据 |

## 5. 可靠性

| 项 | 状态 | 说明 |
|----|------|------|
| 并发安全 | ✅ | 模型加载线程锁 + 切换释放；抽帧唯一文件名；推理全局互斥（前端） |
| 结果可复现 | ✅ | 结果 JSON 幂等；评测随机性 K=3 仅投票按钮 |
| 错误处理 | ✅ | 异常带 detail 返回；排错见 `docs/排错记录.md` |

---

## 结论

本地开发工具无鉴权/密钥/SQL 风险；路径穿越与命令注入已防护。**上线前两项必做**：CORS 收紧（G6）、上传文件校验（G6）。
